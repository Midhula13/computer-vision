## 📂 Programs Included

| # | Program | Description |
|---|---|---|
| 01 | RGB to Grayscale | Convert color images to grayscale format |
| 02 | Image Resizing | Scale images to custom dimensions |
| 03 | Image Cropping | Extract specific regions from images |
| 04 | Histogram Equalization | Enhance low contrast images |
| 05 | Edge Detection | Detect edges using filters |
| 06 | Color Space Conversion | Convert between RGB, HSV, BGR formats |

## 🚀 How to Run

### 1. Clone this repository
git clone https://github.com/Midhula 13/computer-vision-fundamentals.git
cd computer-vision-fundamentals

### 2. Install dependencies
pip install opencv-python numpy matplotlib

### 3. Run any program
python rgb_to_grayscale.py
python histogram_equalization.py
python edge_detection.py
